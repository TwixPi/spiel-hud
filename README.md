# TwixPi Spiel-HUD

Downloads für das Spiel-HUD von Twix. Herunterladen und Anleitung: **[twixpi.de/hud](https://twixpi.de/hud)**

Pixel-HUD für Windows: FPS, CPU, GPU, Ping oben über dem Spiel, dazu eine Discord-Karte (wer im Sprachkanal ist und wer spricht).
Hier liegen nur die fertigen Versionen (Releases), das HUD aktualisiert sich darüber selbst.
